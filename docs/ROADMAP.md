# Roadmap

## Umgesetzt

1. **Grundgerüst**: Vite + React + TypeScript, Vitest, CI und Deployment auf GitHub Pages, Hash-Routing
2. **Mehrere Objekte, Export/Import**: versioniertes JSON-Schema (`immobilienrechner/1`), Autosave im Browser, Import mit Vorschau (hinzufügen, ersetzen, überspringen), „Alle Daten löschen“
3. **Finanzierung & AfA**: mehrere Darlehen, Zinsbindung mit Anschlusszins, monatlicher Tilgungsplan, Sondertilgung, AfA linear/degressiv, Grundstücksanteil in % oder €
4. **Steuerprofil**: Einkommensverlauf mit Stufen und Steigerung, Familienstand im Zeitverlauf, chronologische Verteilung der Steuerwirkung im Portfolio
5. **Gesamtübersicht**: Kennzahlen, Vermögensentwicklung und Cashflow je Objekt, Jahrestabelle, Steuerverteilung je Jahr
6. **Tracking**: Plan beim Kauf einfrieren, Monats- und Jahreswerte, Stichtage, Plan-Ist-Vergleich, Hochrechnung ab Ist-Stand, CSV-Export
7. **Weitere Steuerdetails**: Möbel-AfA, Bereitstellungszinsen, Denkmal-AfA (§7i/§7h)

## Ideen für später

- Verkauf mit Spekulationsfrist und Veräußerungsgewinn
- KfW-Förderdarlehen mit Tilgungszuschuss und tilgungsfreien Jahren
- Sonder-AfA §7b, Denkmal-Förderung bei Selbstnutzung (§10f)
- Indexierung des Steuertarifs für künftige Jahre
- Synchronisation zwischen Geräten (aktuell über Export/Import)
